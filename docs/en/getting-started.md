# Getting started

## Requirements

- macOS 13 or later
- Xcode 15 or later (Swift 5.9 or later)

Download Antlers from its distribution page and launch the app. If macOS displays a security warning on first launch, first confirm that the app came from a trusted source. Then choose **System Settings → Privacy & Security → Open Anyway**. You do not need to disable Gatekeeper.

## Run from source

From the cloned repository, run:

```sh
swift build
swift run Antlers
```

Run tests with:

```sh
swift test
```

To create a `.app` bundle for local use, run:

```sh
./bundle.sh
./scripts/verify-release.sh Antlers.app
```

The `.app` generated by `bundle.sh` is not for third-party distribution. Sign it with a Developer ID certificate and notarize it before distributing it.

## First screen

At launch, Antlers shows two file lists and a message area at the bottom. The pane with the bright border is the active pane.
