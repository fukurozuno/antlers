# Basic operations

## Panes and cursor

Use `Tab` to switch the active pane, or `Left` and `Right` to activate a specific pane. Move the cursor with `Up`, `Down`, `PageUp`, and `PageDown`.

By default, `Enter` opens the selected directory. Use `Backspace` to go to the parent directory. `Command+Left` and `Command+Right` move backward and forward through navigation history.

## Selection and marking

Use `Space` to mark the item at the cursor. By default, the cursor then advances to the next item. `Shift+Space` marks an item and moves to the previous item. Mark several items before copying, moving, or sending them to the Trash.

## Navigate quickly

- `J`: show bookmarks
- In the bookmark list, use `1` through `9` and `0` to choose the first ten entries
- `Shift+J`: enter a path directly
- `H`: show the active pane's history
- `O`: set the active pane to the opposite pane's path
