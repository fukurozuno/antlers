# V0.6.0 Release notes

## Highlights

- Browse ZIP contents inside a pane.
- Extract ZIP files and compress marked items into ZIP files.
- Added a keyboard-driven operation menu and an application-selection menu.
- Added the Incremental search priority setting.
- Added the Treat ZIP files as directories setting.
- Changed the default range-selection shortcut to `Shift+Control+Space`.
- Changed the default context-menu shortcut to `/`.
