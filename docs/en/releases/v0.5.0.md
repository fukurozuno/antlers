# V0.5.0 Release notes

## Highlights

- Added an auxiliary preview pane that shows the selected item alongside the left and right file lists.
- Use `Shift+V` to show or hide the preview pane. In General settings, choose its side; a changed width is restored at the next launch.
- Press `Option+V` to enter preview mode, then use `Option+Left` and `Option+Right` to adjust the preview divider.
- Added a shared reusable pattern history for file masks and wildcard marking.
- Locations now display the `Command+E` shortcut for ejecting the selected volume.
