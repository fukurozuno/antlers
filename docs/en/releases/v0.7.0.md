# V0.7.0 Release notes

## Highlights

- Added a command palette. Open it with `Shift+?` or `Command+Shift+P`, the `?` title-bar button, or the Help menu.
- Search commands by name, keyword, or key. Unavailable commands show a reason based on the current selection or marks. Recently used commands appear first.
- Added command search and **Search by key** to Keybindings. Inspect a sequence, reassign or remove it, or assign an available sequence to a command.
- Added a setting to show or hide the title-bar command palette button. It is visible by default.
- When adding new default shortcuts to existing custom settings, conflicting assignments are skipped.

See [Keybindings](../keybindings.md) and [Settings and appearance](../settings.md) for usage.
