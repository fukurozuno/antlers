# V0.2.0 Release notes

Key changes since V0.1.0.

## New features and improvements

- You can now configure an application and a list color for each file extension. The default shortcut for opening an item with its configured application is `Control+Return`.
- Expanded themes with built-in Light, Dark, Solarized Light, Solarized Dark, Nord, and Dracula options, plus a sample pane for previewing the theme being edited.
- Added zebra-striping for file lists.
- You can now import only themes and keybindings from a settings file.
- Improved the bookmarks settings list and prompt you to add or update pending edits before closing Settings.
- Conflict dialogs during copy and move operations are now keyboard-accessible: Return to proceed, `S` to skip, `N` to proceed only if newer, Esc to cancel, and Space to apply the choice to remaining conflicts.
- Long filenames can now be reviewed and edited by horizontally scrolling the Rename field.

## Bug fixes

- Fixed an issue that could incorrectly disable menu items.
- Fixed standard Cut, Copy, and Paste shortcuts (`Command+X`, `Command+C`, and `Command+V`) in text fields such as direct-path input, Rename, and New Folder.
- Fixed behavior when clicking the window's close button directly.
- When cancelling a copy or move conflict dialog, the result message now shows the number of unprocessed items.
