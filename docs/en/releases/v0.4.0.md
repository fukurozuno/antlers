# V0.4.0 Release notes

## Highlights

- Added file-list font-size settings and the `Command+Shift++`, `Command+-`, and `Command+0` shortcuts.
- Added confirmed ejection of removable volumes from Locations.
- Added **Other** to file-type settings. It applies a configured application and list color to ordinary files without a specific extension setting.
- Added file dragging to other applications. Enable it in General to provide files as copies from a file list.
- The in-pane preview now shows the name of the previewed file.
