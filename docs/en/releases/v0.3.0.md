# V0.3.0 Release notes

Key changes since V0.2.0.

## Public source and builds

- Added source code, tests, and build scripts to the public repository.
- The project can now be built, tested, and launched with `swift build`, `swift test`, and `swift run Antlers`.
- Added `bundle.sh` for creating a `.app` bundle and `scripts/verify-release.sh` for pre-release checks. The generated `.app` includes localized resources and the app icon, then receives an ad hoc signature for local use.

## New features and improvements

- Incremental search can now use prefix, contains, or exact matching.
- Bookmark lists now support numeric shortcuts: `1` through `9` and `0` jump to the first ten entries.
- Added commands for copying file names, parent directory paths, and full paths to the clipboard. The default shortcuts are `P, 1`, `P, 2`, and `P, 3`.
- Paths can also be copied from the context menu.
- Function keys can now be explicitly assigned in keybindings.
- Improved result messages for copy, move, delete, and file-name copy operations.
- Added a setting for the number of file-operation detail log entries. Use `0` to show all entries.

## Documentation

- Added README instructions for building from source, running tests, and creating a `.app` bundle.
- Documented the Bundle Identifier as `io.github.fukurozuno.antlers`.

## Notes

- The `.app` generated by `bundle.sh` is for local use. For third-party distribution, sign it with a Developer ID certificate and complete Apple notarization.
