# ファイル操作

操作対象は、マーク済み項目がある場合はそれら、ない場合は現在選択中の項目です。操作先は原則として逆側のペインの現在位置です。

| キー | 操作 |
| --- | --- |
| `C` | 逆側ペインへコピー |
| `M` | 逆側ペインへ移動 |
| `D` | ゴミ箱へ移動 |
| `R` | 選択中項目をリネーム |
| `Shift+R` | 同じ場所に別名でコピー |
| `K` | 現在の場所にフォルダを作成 |
| `P, 1` | ファイル名をクリップボードへコピー |
| `P, 2` | 親ディレクトリのパスをクリップボードへコピー |
| `P, 3` | フルパスをクリップボードへコピー |
| `_` / `Shift+_` | コンテキストメニューを表示 |

## コピー前の確認

コピーは実行前に対象件数、操作先、対象パスを確認できます。確認画面で内容を見直してから **コピー** を選んでください。確認を中止する場合は **キャンセル** を選びます。

![コピー前の確認画面](../assets/screenshots/copy-dialog.png)

既存の項目を上書きする可能性がある操作では、明示的な確認が必要です。削除は恒久削除ではなくゴミ箱への移動です。詳細は [安全な操作](safety.md) を参照してください。

## クリップボードとコンテキストメニュー

`P, 1`、`P, 2`、`P, 3` で、操作対象のファイル名、親ディレクトリのパス、フルパスを複数行テキストとしてコピーできます。操作対象は通常のファイル操作と同じく、マーク済み項目がある場合はそれら、ない場合は現在選択中の項目です。

`_` または `Shift+_` でコンテキストメニューを表示できます。メニューからは、開く、指定アプリで開く、Finder で表示、パスをコピー、コピー、移動、リネーム、別名コピー、フォルダ作成を実行できます。

## 他のアプリケーションへドラッグする

General の「他のアプリケーションへのファイルドラッグを許可する」を有効にすると、ファイル一覧から他のアプリケーションへファイルをドラッグできます。ドラッグはコピーとして提供され、Antlers 内の項目を移動しません。

マーク済み項目からドラッグを開始した場合は、すべてのマーク済み項目を渡します。未マーク項目から開始した場合は、その項目だけを渡します。
