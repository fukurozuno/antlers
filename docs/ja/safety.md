# 安全な操作

Antlers は、便利さよりデータ損失の防止を優先します。

- `D` による削除は恒久削除ではなく、ゴミ箱への移動です。
- コピー、移動、ゴミ箱への移動、終了の前に確認を表示する設定を利用できます。リネーム時の上書き確認は常に表示されます。
- 上書きが発生する操作は、内容を確認してから実行します。
- ファイル操作の結果は、画面下部のメッセージ領域で確認できます。
- ZIPの展開では、既存の出力先を上書きせず、一時フォルダへの展開が成功した場合だけ確定します。
- ZIP内の絶対パスや `..` を含む危険なパス、symlink、サイズ・項目数の上限を超えるアーカイブは拒否します。

重要なファイルを操作する前には、バックアップが利用できることを確認してください。確認画面では、操作対象、件数、操作先を必ず見直してください。
