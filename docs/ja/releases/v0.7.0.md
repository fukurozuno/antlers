# V0.7.0 リリースノート

## 主な変更

- コマンドパレットを追加しました。`Shift+?` または `Command+Shift+P`、ウィンドウ上部の `?` ボタン、ヘルプメニューから開けます。
- 機能名、キーワード、キーから操作を検索できます。選択中の項目やマークの状態に応じて、使用できない操作には理由を表示します。最近使用した機能も一覧の先頭に表示します。
- Keybindings 設定に機能の検索と「キーから検索」を追加しました。入力したキー列の割り当てを確認し、別の機能への割り当て変更、解除、未割り当てキーの登録ができます。
- ウィンドウ上部のコマンドパレットボタンを表示・非表示にする設定を追加しました。既定では表示します。
- 既存のカスタムキー設定に新しい既定キーを取り込むときは、衝突する割り当てを追加しないようにしました。

操作方法は [キーバインド](../keybindings.md) と [設定と外観](../settings.md) を参照してください。
