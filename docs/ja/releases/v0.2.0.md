# V0.2.0 リリースノート

V0.1.0 からの主な変更です。

## 機能追加・改善

- 拡張子ごとに、ファイルを開くアプリケーションと一覧表示色を設定できるようになりました。指定アプリで開く操作は既定で `Control+Return` です。
- テーマ機能を拡張しました。Light、Dark、Solarized Light、Solarized Dark、Nord、Dracula の組み込みテーマを追加し、編集中のテーマをサンプルペインで確認できます。
- ファイル一覧にゼブラ背景表示を追加しました。
- 設定ファイルから、テーマとキーバインドだけを選んでインポートできるようになりました。
- 登録パス設定の一覧表示を改善し、未反映の編集内容がある場合は、追加または更新を促すようにしました。
- コピー・移動時に同名項目が見つかった場合の確認ダイアログをキーボードで操作できるようにしました。Return で実行、`S` でスキップ、`N` で「新しい場合のみ」、Esc で中止、Space で以降への適用を切り替えられます。
- リネーム入力欄で長いファイル名を横スクロールして確認・編集できるようにしました。

## 不具合修正

- 一部のメニューが意図せず無効になる問題を修正しました。
- パス入力・リネーム・フォルダ作成などのテキスト入力欄で、`Command+X`、`Command+C`、`Command+V` による標準の切り取り、コピー、貼り付けが使えない問題を修正しました。
- ウィンドウの閉じるボタンを直接クリックした場合の挙動を修正しました。
- コピー・移動の競合確認をキャンセルしたとき、未処理の項目数を結果メッセージに表示するようにしました。
