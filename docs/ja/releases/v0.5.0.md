# V0.5.0 リリースノート

## 主な変更

- 左右のファイル一覧に加えて、選択項目を表示する補助プレビューペインを追加しました。
- `Shift+V` で補助プレビューペインを表示・非表示にできます。General では表示位置を左右から選べ、変更した幅は次回起動時にも復元されます。
- `Option+V` でプレビューモードに入り、`Option+Left` と `Option+Right` でプレビュー境界を調整できます。
- ファイルマスクとワイルドカードマークで入力したパターンを共通履歴に保存し、再利用できるようになりました。
- 場所一覧に、選択中ボリュームを取り外す `Command+E` の案内を表示するようになりました。
