# V0.3.0 リリースノート

V0.2.0 からの主な変更です。

## 公開ソースとビルド

- ソースコード、テスト、ビルドスクリプトを公開リポジトリに含めました。
- `swift build`、`swift test`、`swift run Antlers` でビルド、テスト、起動できる構成にしました。
- `.app` バンドル作成用の `bundle.sh` と、公開前確認用の `scripts/verify-release.sh` を追加しました。生成される `.app` にはローカライズリソースとアプリアイコンを同梱し、ローカル実行用の ad hoc 署名を付与します。

## 機能追加・改善

- インクリメンタルサーチの照合方法を、前方一致、部分一致、完全一致から選べるようにしました。
- 登録パス一覧で `1` から `9`、`0` の数字キーを使って、先頭 10 件へすばやく移動できるようにしました。
- ファイル名、親ディレクトリのパス、フルパスをクリップボードへコピーするコマンドを追加しました。既定キーは `P, 1`、`P, 2`、`P, 3` です。
- コンテキストメニューからもパスをコピーできるようにしました。
- ファンクションキーをキーバインドへ明示的に割り当てられるようにしました。
- コピー、移動、削除、ファイル名コピー時の結果メッセージを改善しました。
- ファイル操作の明細ログ表示件数を設定できるようにしました。`0` を指定すると全件を表示します。

## ドキュメント

- ソースからのビルド、テスト、`.app` バンドル作成手順を README に追加しました。
- Bundle Identifier を `io.github.fukurozuno.antlers` として明記しました。

## 注意事項

- `bundle.sh` で生成した `.app` はローカル実行用です。第三者へ配布する場合は、Developer ID による署名と Apple の notarization を完了してください。
