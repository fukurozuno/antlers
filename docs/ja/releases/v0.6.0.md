# V0.6.0 リリースノート

## 主な変更

- ZIPファイルの内容をペイン内で閲覧できるようになりました。
- ZIPファイルの展開と、マーク済み項目のZIP圧縮に対応しました。
- キーボード操作用の操作メニューと、アプリケーション選択メニューを追加しました。
- インクリメンタルサーチ優先設定を追加しました。
- ZIPをディレクトリとして扱う設定を追加しました。
- 範囲選択の既定キーを `Shift+Control+Space` に変更しました。
- コンテキストメニューの既定キーを `/` に変更しました。
