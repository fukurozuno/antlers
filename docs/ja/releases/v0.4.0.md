# V0.4.0 リリースノート

## 主な変更

- ファイル一覧のフォントサイズを設定および `Command+Shift++`、`Command+-`、`Command+0` で変更できるようになりました。
- 場所一覧から、取り外し可能なボリュームを確認後に取り外せるようになりました。
- 拡張子別設定に「その他」を追加しました。具体的な拡張子が設定されていない通常ファイルへ、指定アプリと表示色を適用できます。
- 他のアプリケーションへのファイルドラッグを追加しました。General で有効にすると、一覧からファイルをコピーとして渡せます。
- ペイン内プレビュー中に、プレビュー対象のファイル名を表示するようになりました。
