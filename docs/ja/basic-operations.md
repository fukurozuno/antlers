# 基本操作

## ペインとカーソル

`Tab` でアクティブペインを切り替えます。`Left` と `Right` は、それぞれ左・右のペインを直接アクティブにします。`Up`、`Down`、`PageUp`、`PageDown` でカーソルを移動します。

`Enter` は既定では選択中のディレクトリを開きます。`Backspace` で親ディレクトリへ戻ります。`Command+Left` と `Command+Right` で移動履歴を前後します。

General の「ZIP ファイルをディレクトリとして扱う」が有効な場合、ZIPファイルを選択して `Enter` を押すと、ZIPの内容をペイン内で閲覧できます。閲覧中はディレクトリを開いたり、`Backspace` でZIP内の親階層または通常のファイル一覧へ戻ったりできます。詳しくは [ZIP／アーカイブ操作](archive-operations.md) を参照してください。

## ファイルをプレビューする

`V` で選択中ファイルのペイン内プレビューを開きます。`Esc` または `Q` でファイル一覧へ戻ります。

`Shift+V` で補助プレビューペインの表示を切り替えます。補助プレビューはアクティブペインの選択項目に追従し、ファイルでは Quick Look と名前・種類・サイズ・更新日時・パスを表示します。ディレクトリまたは未選択時は、現在のディレクトリの項目数とパスを表示します。

補助プレビューペインの位置は General で左右から選べます。`Option+V` でプレビューモードに入り、`Option+Left` と `Option+Right` でプレビューとファイル一覧の境界を調整できます。

## 選択とマーク

`Space` でカーソル位置の項目をマークします。既定では次の項目へ移動します。`Shift+Space` はマーク後に前の項目へ移動します。複数の項目をマークしてからコピー・移動などを実行できます。

## すばやく場所へ移動する

- `J`: 登録パス一覧を開く
- 登録パス一覧では `1` から `9`、`0` で先頭 10 件を選ぶ
- `Shift+J`: パスを入力して移動する
- `H`: 現在のペインの履歴を表示する
- `O`: アクティブペインを逆側ペインと同じパスにする

`L` で場所一覧を開きます。取り外し可能なボリュームを選択中は、`Command+E` で確認後に取り外せます。

`T` で Finder タグの一覧を開き、選択したタグでファイルを検索できます。`Shift+T` は選択中項目のタグを設定・解除します。

## 検索、絞り込み、マーク

`F` でインクリメンタルサーチを開始します。照合方法は General で前方一致、部分一致、完全一致から選べます。

「インクリメンタルサーチ優先」を有効にすると、修飾キーなしの英数字・記号キーが検索入力に優先して使われます。有効中は、それらのキーを通常のキーバインドとして実行できません。

`Shift+@` はワイルドカードマーク、`Shift+:` はファイルマスクです。どちらも `*` と `?` を使え、確定したパターンは共通の履歴に保存されます。入力欄のクリック、`Up`、または `Down` で履歴を表示し、`Return` で選択したパターンを再利用できます。
